- The repository uses two patterns for rule exceptions:
  - an inline `// biome-ignore <rule>: <reason>` with a spec citation, for single sites (`line-core` mixins,

- An inline comment changes `src` in four published packages, so PROCESS §6 asks for four patch changesets that
  change nothing for consumers. A `biome.json` override changes no published output.
