## Acceptance criteria
- Every dependency in scope resolves to the latest version in its current major in `bun.lock`.
- Spec §6.A A2 and A3 match the manifests, and the Rolldown note states the version Vite 8.3.4 ships
  (`~1.2.12`).
- `bun run lint`, `bun run build`, `bun test` for every package with tests, root `bun run test` and
  `bun run e2e` pass.
- Changesets follow PROCESS §6. `line-core` gets a patch if its Zag.js range moves, and any CSS package whose
  built output changes gets a patch.
